# BKBIET College Showcase Website

Static React + Vite frontend showcase for B.K. Birla Institute of Engineering & Technology, Pilani.

## Sections included
- Responsive college header and navigation
- Hero slider
- Campus notices, upcoming events and Student's Corner
- Student Highlights cards
- Academic / Admission Circulars and Notices / Downloads panels
- Campus Life six-image editorial grid
- Institutional footer with college identity and three quick-link columns

The three sections added in this revision intentionally follow the supplied reference layouts closely while using original BKBIET showcase wording and the project's own campus photographs. The supplied reference screenshots are not used as website assets.

All notices, events and highlight stories are illustrative frontend content only. No backend or database is connected.

## Run locally
Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite, usually http://localhost:5173.

## Production build
```bash
npm run build
npm run preview
```
